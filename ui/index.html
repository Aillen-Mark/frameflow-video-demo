三步，开始你的创作

    上传 JPG、PNG 或 WebP，也可以使用山湖示例。

  2. 写下画面描述

  3. 生成、播放与下载

    保持页面前台，等待 5–10 秒，下载浏览器生成的视频。

演示与 API 两种模式

本地演示使用图片运镜；API 模式将图片提交到已配置的供应商。进入“API 接入”保存凭据并测试连接后，在创作页选择服务即可提交。两种模式的额度和记录分别保存。

重置演示空间？

这会移除本浏览器中的演示作品，并恢复 10 次演示额度。请先下载需要保留的视频。

粘贴 API 配置

可粘贴导出的 JSON。密钥也可填入 credentials 对象，导入仅填表，不会自动提交。

关联供应商任务

在供应商控制台找到本次已提交任务的 ID。关联只查询既有任务，不会重新生成。
